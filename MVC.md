# Архитектура MVC

MVC (Model-View-Controller) — архитектурный подход, при котором
приложение разделяется на три основных компонента: Model, View
и Controller.

## Model

Model отвечает за данные приложения и бизнес-логику.

Основные задачи Model:

- хранение данных;
- получение данных;
- изменение данных;
- взаимодействие с базой данных;
- выполнение бизнес-логики.

Пример: класс, который получает из базы данных список студентов.

## View

View отвечает за представление информации пользователю.

Основные задачи View:

- отображение данных;
- формирование пользовательского интерфейса;
- вывод результатов работы программы.

Пример: HTML-страница, отображающая список студентов.

## Controller

Controller связывает Model и View.

Основные задачи Controller:

- получение действий пользователя;
- вызов необходимых методов Model;
- выбор данных для отображения;
- передача данных во View.

Пример: обработчик HTTP-запроса, который получает данные
из Model и передаёт их на HTML-страницу.

## Преимущества MVC

- разделение ответственности между компонентами;
- упрощение сопровождения приложения;
- возможность независимо изменять интерфейс и бизнес-логику;
- удобство тестирования;
- улучшение структуры проекта.

## Пример

Для веб-приложения со списком студентов:

Model — получает студентов из базы данных.

View — отображает таблицу студентов.

Controller — принимает запрос пользователя, получает список
студентов из Model и передаёт его во View.
