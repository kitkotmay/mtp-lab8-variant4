# Реализация архитектуры MVC

В рамках лабораторной работы №8 разработано консольное приложение
для хранения и отображения информации о студентах с использованием
архитектурного шаблона MVC (Model-View-Controller).

Программная реализация находится в каталоге `mvc_app`.

## Структура приложения

```text
mvc_app/
├── __init__.py
├── model.py
├── view.py
├── controller.py
└── main.py
```

## Model

Файл: `mvc_app/model.py`.

Класс `StudentModel` представляет слой Model.

Он отвечает за хранение и обработку данных студентов.

Основные методы:

- `add_student()` — добавляет студента;
- `get_students()` — возвращает список студентов.

Model не занимается отображением информации пользователю.

## View

Файл: `mvc_app/view.py`.

Класс `StudentView` представляет слой View.

Он отвечает только за отображение информации пользователю.

Основные методы:

- `show_title()` — отображает заголовок;
- `show_students()` — отображает список студентов;
- `show_message()` — отображает информационное сообщение.

View не изменяет данные Model.

## Controller

Файл: `mvc_app/controller.py`.

Класс `StudentController` представляет слой Controller.

Controller связывает Model и View. Он вызывает методы Model для
работы с данными и передаёт полученный результат во View.

Основные методы:

- `add_student()` — передаёт данные нового студента в Model;
- `show_students()` — получает список студентов из Model и
  передаёт его во View.

## Точка входа

Файл: `mvc_app/main.py`.

В программе создаются объекты `StudentModel`, `StudentView`
и `StudentController`.

Работа приложения происходит следующим образом:

1. `main.py` создаёт Model, View и Controller.
2. Controller получает данные о новом студенте.
3. Controller передаёт данные в Model.
4. Model сохраняет данные.
5. Controller получает список студентов из Model.
6. Controller передаёт список во View.
7. View отображает результат пользователю.

## Схема MVC

```text
Пользователь
     |
     v
 Controller
   /     \
  v       v
Model    View
  |       |
данные   вывод
```

Таким образом, приложение разделено на независимые компоненты
Model, View и Controller.

## Запуск приложения

Из корневой директории проекта:

```powershell
python -m mvc_app.main
```

------------------------------------------------------------

2. Иванов Иван Иванович | группа: 221141р | вариант: 2
