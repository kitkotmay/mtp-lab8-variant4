\## Публикация собственного пакета в TestPyPI



В рамках задания повышенной сложности №9 создан собственный Python-пакет `kovalevich-utils-221141r`.



\### Сборка пакета



Сборка пакета выполнена командой:



python -m build



Проверка собранных файлов:



python -m twine check dist/\*



Проверка завершилась успешно для файлов `.whl` и `.tar.gz` (PASSED).



\### Публикация в TestPyPI



Публикация пакета выполнена командой:



python -m twine upload --repository testpypi dist/\*



Для авторизации использовался API-токен TestPyPI.



\### Проверка установки из TestPyPI



Для подтверждения успешной публикации пакет был установлен непосредственно из TestPyPI:



python -m pip install --index-url https://test.pypi.org/simple/ --no-deps kovalevich-utils-221141r==0.1.0



После установки работа пакета проверена командой:



python -c "from kovalevich\_utils import square, cube; print(square(5), cube(3))"
